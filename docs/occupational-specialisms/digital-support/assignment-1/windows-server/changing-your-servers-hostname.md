# Changing Your Server's Hostname

## Guided Steps

1. From the **Server Manager** application, select **Local Server** from the left side-panel.
2. Click on the current computer name. e.g WIN-T1000***
3. Click the **Change** button in the centre of this window.
4. Update the computer name, then click **Ok**, and then **Apply**

**Note**: If this step is completed after the configuration of DHCP, DNS, AD DS, and WDS it can cause unexpected/wierd behaviour. I advise completing this step soon after installation.
