# The Six Vs of Big Data

*Big Data* is a term used to refer to a dataset that is too large or complex to be process, stored, or manipulated by traditional hardware and software. E.g. Not something that you could deal with on your computer using Excel. 

There are categories that are used to define traits and qualities of big data, presented as the six Vs of Big Data.

## The Six Vs

### Volume 

Volume refers to the sheer size of the data being generated and gathered. Businesses dealing with big data will often measure data in terabytes, petabytes, or in some cases - exabytes. 

There are over 15Bn IoT devices connected to the internet gathering information, social media platforms gather views, likes, and shares. Handling this amount of data requires complex storage solutions, and scalable infrastructure.
### Variety

Variety refers to the different forms and types of data that are generated and collected. Prior to the digital revolution, most data was in a structured form that came from traditional databases. Since the rise of big data, there has been a jump in the amount of unstructured and semi-structured data.

* *Structured* - Data the is arranged in rows and columns, like data in an Excel spreadsheet.
    * *Examples* - Student records, patient records,
* *Unstructured* - Data that does not have a pre-defined format. Such as text, images, and videos.
    * *Examples* - Written student reports, doctors notes, photographs
* *Semi-structured* - Data that does not fit the traditional rows and columns format but is stored through another method such as JSON or XML files.
    * *Examples* - Fitness data from a smartwatch, data generated by a insurance telematics box.

Data that comes in a mixture of structure types create some complexity for processing. There are specialised tools that are designed to managed these different data sets. 
### Velocity

The speed at which the data is generated, processed, and analysed. Data is often generated in real time or very close to, requiring systems that can keep up. Fast moving data such as financial, social media, and IoT sensors require quick processing and responsive storage solutions. 

Stock markets and cryptocurrency platforms for example generate masses of data every second, they rely on high-velocity data processing to executing trades in milliseconds. 
### Veracity

Veracity is the trustworthiness and reliability of the data set. Is the data free of bias or inconsistencies.

Poor quality data can result in an organisation making decisions resulting in a negative outcome. A sensor producing inaccurate readings could invalidate a research project. 
### Value

Value refers to how useful a data set is, what level of impact could it give to a business. while organisations are collecting terabytes of data, is it data that they can draw insights from?

For example, Amazon collect a large amount of shopping data while customers are using their platform. By analysing this data, they can generate personal recommendations, predict trends in demands that should in theory result in increased sales and customer satisfaction.
### Variability

Variability is the unpredictable changes, inconsistencies, and outliers that may occur in a data set. These changes and jumps in the data flow can require additional processing or techniques to identify.

This creates a challenge where data scientists have to interpret the data and adapt accordingly to ensure the data model remains consistent and reliable.

For example, trends can vary wildly depending on time of day, current events, and other similar factors.
