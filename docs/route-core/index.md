# Route Core

The Route Core is the content shared by the Digital T-Levels. Digital Support and Security (DSS) and Digital Software Development (DSD) cover the same core topics, apart from content area 2, which is specific to each pathway.

The two specifications number some content areas differently, so pages here are grouped by topic. Use the table to find the content area number for your pathway.

| Topic | DSS | DSD |
|---|:-:|:-:|
| [Problem Solving](problem-solving/index.md) | 1 | 1 |
| Introduction to Digital Support | 2 | n/a |
| Introduction to Programming | n/a | 2 |
| [Data](data/index.md) | 3 | 6 |
| Legislation and Regulatory Requirements | 4 | 4 |
| Business Context | 5 | 5 |
| Emerging Issues | 6 | 3 |
| [Digital Environments](digital-environments/index.md) | 7 | 7 |
| [Security](security/index.md) | 8 | 8 |

Topics without a link do not have pages yet.

Content area numbers are taken from the Pearson specifications for [Digital Support and Security](https://qualifications.pearson.com/content/dam/pdf/TLevels/digital-support-and-security/2025/specification-and-sample-assessment-materials/digital-dss-specification.pdf) and [Digital Software Development](https://qualifications.pearson.com/content/dam/pdf/TLevels/digital-software-development/2025/specification-and-sample-assessment-materials/digital-dsd-specification.pdf).
