# Agile vs Waterfall Methodologies

## Waterfall
A linear, sequential approach to software/project development. Each phase must be completed before the next begins.

> Useful when: requirements are clear and fixed.

## Agile
An iterative, flexible approach that promotes continuous testing and feedback. Features are developed in short "sprints."

> Useful when: requirements are likely to evolve or change during the project.

## Comparison Table

| Feature        | Waterfall              | Agile                      |
|----------------|------------------------|----------------------------|
| Flexibility     | Low                    | High                       |
| Feedback Loops | At the end             | Frequent during sprints    |
| Documentation  | Comprehensive upfront  | Evolving and lightweight   |
